A mine-sweeper game implemented in Python. 
The game allows players to uncover tiles on a grid, avoiding hidden mines. 
The objective is to clear the board without detonating any mines.

Dynamic scaling have been implemented along with game_mode, 5 different stages is including
easy, medium, hard, extreme, insane and custom. Each of these stages have their own
grid size and mines. 

Future implements will feature the rules, timer, score and game conditions

More information about the game, including installation instructions, gameplay mechanics, and how to run the game, 
can be found in the following sections in future updates to this README file.

Google Gemini have been used in this project for game diagnostics,testing and correction, ensuring a smooth and 
bug-free gaming experience.
